## 🔧 About the Model

This model is a fully detailed **6-sided dice** with accurately placed and recessed circular pip dots on each face. It is one of the more detailed models in this collection, requiring precise placement of multiple hole features. Key design features include:

- **Cubic body** — equal width, height, and depth for a perfect cube shape
- **Recessed pip dots** — circular pocket cuts on each face representing numbers 1 through 6
- **Visible faces** — top, front, and right faces all show their respective pip patterns
- **Realistic proportions** — modeled to resemble a standard game die
- Modeled with standard **Front, Top, and Right** reference planes in Onshape

## ⚙️ How It Was Built

| Step | Feature | Description |
|------|---------|-------------|
| 1 | Sketch + Extrude | Drew a square and extruded into a cube |
| 2 | Fillet *(optional)* | Rounded edges for a realistic look |
| 3 | Circular Sketch | Drew circles on each face for pips |
| 4 | Pocket / Cut | Extruded cuts to recess the pip dots |
| 5 | Linear Pattern | Used pattern feature to repeat pip holes |
