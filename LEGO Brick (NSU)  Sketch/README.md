# LEGO Brick (NSU) — 3D CAD Model

## 🔧 About the Model

This model is a **LEGO-style rectangular brick** with 6 raised cylindrical studs arranged in a 2×3 grid on the top face — closely resembling a standard LEGO 2×3 plate or brick. Key design features include:

- **Flat rectangular body** — the base brick/plate shape
- **6 raised cylindrical studs** — arranged in a 2 columns × 3 rows pattern on the top face
- **Uniform stud spacing** — evenly distributed to match standard LEGO proportions
- **Dark grey/graphite color** in the Onshape render
- Modeled with standard **Front, Top, and Right** reference planes in Onshape

## ⚙️ How It Was Built

| Step | Feature | Description |
|------|---------|-------------|
| 1 | Sketch + Extrude | Drew a rectangle and extruded into a flat brick body |
| 2 | Stud Sketch | Drew a circle on the top face for one stud |
| 3 | Extrude Stud | Extruded the circle upward to create a raised cylinder |
| 4 | Linear Pattern | Repeated the stud using a 2×3 linear pattern |
| 5 | Appearance | Applied dark grey color/material to the model |
