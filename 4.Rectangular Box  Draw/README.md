## 🔧 About the Model

This model represents a **solid rectangular enclosure or housing**, commonly used in electronics and mechanical assemblies. Key design features include:

- **Large solid rectangular body** — wider than it is tall, with clean boxy geometry
- **Two-tone shading** — lighter blue top face and darker grey-blue front face, showing realistic 3D depth and lighting
- **1 circular port** on the front face — could serve as a cable entry, ventilation hole, button cutout, or connector port
- Modeled with standard **Front** and **Right** reference planes in Onshape

## 🚀 Getting Started

### View in Onshape

1. Open [Onshape](https://www.onshape.com/) and sign in (free account available)
2. Open the shared document link *(add your link here)*
3. Use the toolbar to rotate, pan, and inspect the model

### Navigation Controls

| Action | Control |
|--------|---------|
| Rotate | Right-click + drag |
| Pan | Middle-click + drag |
| Zoom | Scroll wheel |
| Reset view | Press `Home` or click the 🏠 icon |
