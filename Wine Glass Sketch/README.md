## 🔧 About the Model

This model is a fully detailed **wine glass / goblet** — the most complex and visually impressive model in this collection. It demonstrates advanced CAD techniques including revolve operations and custom plane creation. Key design features include:

- **Large hollow spherical bowl** — the main cup body, open at the top
- **Cylindrical stem** — a thin connector between the bowl and base
- **Disc-shaped base / cap** — flat circular foot for stability
- **Custom Plane 1 & Plane 2** — additional construction planes created to assist in building the complex curved geometry
- **Smooth curved surfaces** — achieved through revolve or loft operations
- Standard reference planes visible: **Front, Top, Right**

## ⚙️ How It Was Built

| Step | Feature | Description |
|------|---------|-------------|
| 1 | Custom Planes | Created Plane 1 & Plane 2 for reference geometry |
| 2 | Profile Sketch | Drew the side profile of the glass (half cross-section) |
| 3 | Revolve | Revolved the profile 360° around the central axis |
| 4 | Shell | Hollowed out the bowl to create the cup cavity |
| 5 | Base Sketch | Added circular base disc at the bottom |
| 6 | Extrude Base | Extruded the base into a flat stable foot |
