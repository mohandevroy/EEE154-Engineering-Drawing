## 🔧 About the Sketch

This is a **flat 2D profile sketch** of a rounded octagonal shape, lying on the **Top plane**. It is an intermediate step in the CAD workflow — once extruded, it becomes a full 3D solid. Key features include:

- **Rounded octagonal outline** — a shape between an octagon and an oval, with chamfered/clipped corners
- **Dashed construction circle** — used as a reference guide to maintain symmetry and proportions during sketching
- **Constraint points (dots)** — visible at each vertex/corner where sketch lines meet, confirming fully constrained geometry
- **Center origin point (⊙)** — the sketch is centered at the Onshape origin
- All three reference planes visible: **Front, Top, Right**
