## 🔧 About the Sketch

This is a **flat 2D circular profile sketch** lying on the **Top plane**. It is a fundamental CAD sketch — simple yet essential for creating cylindrical geometry. Key features include:

- **Circular outline** — a clean, fully constrained circle
- **Two radial lines** extending from the **center point (⊙)** up to a single vertex on the edge — used to define or display the **radius dimension**
- The lines form a **triangular/cone shape** from center to edge, a classic CAD technique for annotating radius
- **Center origin point (⊙)** — the sketch is centered at the Onshape origin
- All three reference planes visible: **Front, Top, Right**
